# EV-Sales-Insights
EV Market Analysis Dashboard (Excel + Power Pivot + DAX)

This project delivers a complete analytical dashboard for India’s EV market using Excel, PivotTables, Power Pivot, and DAX.
It includes interactive insights on:

EV Sales (2022–2024)

Category-wise performance (2W vs 4W)

State penetration & CAGR calculations

Manufacturer market share & revenue

2030 EV sales forecasting

🔧 Tech Used

Excel PivotTables

Power Pivot + DAX Measures

Interactive Charts

Automated KPIs

Data storytelling visuals




Presentation (storytelling walkthrough)

Perfect for learners exploring data analytics, dashboard design, and DAX.
